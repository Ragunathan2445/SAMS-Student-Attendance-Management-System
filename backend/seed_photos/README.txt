Put real photos here and run:  python -m scripts.seed

File names (JPG, JPEG, PNG or WEBP):
  Students:  student_<ROLL NUMBER>     e.g. student_6A01.jpg, student_8A03.png
  Teachers:  teacher_<TEACHER ID>      e.g. teacher_T1001.jpg, teacher_T1002.jpg

Any student/teacher without a file here gets the drawn placeholder avatar.
Photos are resized to max 600x600 and stored in backend/uploads/photos.
Use only photos you have permission to use (the demo data is synthetic).
